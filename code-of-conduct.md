# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the technical merits of an entry. Harassment, personal attacks, and spam are not tolerated.

Report unacceptable behavior by opening an issue or contacting [@dorsha](https://github.com/dorsha) directly. Reports are handled confidentially.
